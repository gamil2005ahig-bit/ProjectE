# ProjectE

Godot 4 기반의 한국어 경제 시뮬레이터 프로토타입입니다. 정치 시스템과 외부 에셋 없이 건물 생산, 생활 소비, 인구 변화를 틱 단위로 확인합니다.

## 초기 상태

- 인구: 100명
  - 농민 0명
  - 노동자 0명
  - 무직 100명
- 지형 슬롯: 농지 20, 해안 10, 숲 10, 광맥 5
- 시작 배치 건물: 1단계 농장 2개, 1단계 가축 목장 1개, 1단계 벌목장 1개, 1단계 어업 부두 1개
- 초기 재고: 곡물 200, 고기 50, 생선 20, 나무 100, 철 50, 석탄 50, 유황 30, 공구 50, 비료 20, 강철 20, 배 5, 고급 공구 10, 고급 비료 0, 건설력 0

첫 틱부터 무직 인구는 필요한 노동 유형의 유연한 예비 인력으로 사용됩니다. 노동은 `primary` -> `mine` -> `factory` 순서와 배치 순서를 따르며, 건물의 노동 유형에 맞는 농민 또는 노동자만 배치합니다. 남은 typed 인구와 무직은 각 집단에 남습니다.

## 건물과 지형

건물 카탈로그에는 자경 농장, 농장, 가축 목장, 어업 부두, 벌목장, 철 광산, 석탄 광산, 유황 광산, 공구 작업장, 비료 공장, 고급 공구 작업장, 제강소, 조선소, 건설 부문의 14개 건물 유형이 있습니다. 자경 농장은 배치하지 않는 가상 건물이며 빈 농지 슬롯에서만 작동하고 항상 건설 불가입니다.

대시보드의 건설 선택 목록은 자경 농장을 비활성화해 표시하고, 선택한 건물의 비용과 필요한 지형을 보여 줍니다. 건설 비용은 `건설력` 재고에서 즉시 차감합니다. 건설 시 지형 슬롯과 비용을 다시 검증하며, 지형 불일치, 슬롯 부족, 재고 부족, 건설 불가 선택이면 버튼을 비활성화합니다.

## 틱 순서

1. 노동 자동 배치
2. 배치된 건물 생산 및 입력 소비
3. 빈 농지의 가상 자경 농장 생산 1회
4. 생활 소비
5. 인구 증감
6. UI 갱신

일반 건물 생산은 `최대 산출량 * (고용 / 수용 인원)`입니다. 입력이 있는 생산 방식은 각 입력의 `보유량 / 최대 필요량` 중 최솟값을 입력 비율로 사용합니다. 입력 비율과 고용 비율을 곱한 만큼만 입력을 소비하고 산출합니다. 입력 부족은 로그에 기록됩니다.

자경 농지는 빈 농지 슬롯마다 농민 수용 인원 10을 합산합니다. 즉 `aggregate_capacity = 빈 농지 슬롯 * 10`이고, 고용은 이 합계까지 제한되며 최대 산출량에 대한 고용 비율로 산출합니다. "만원 생산"은 농민 10명이 완전 고용되었을 때 곡물 10, 고기 2, 나무 1을 생산하는 최대치라는 뜻이며, 다른 생산과 마찬가지로 고용 비율에 따라 줄어듭니다.

## 생활 소비와 인구

모든 인구는 매 틱 곡물 1을 소비합니다. 단백질 수요는 전체 인구 / 5이며 고기와 생선을 합친 하나의 수요입니다. 두 재고가 모두 있으면 현재 재고 비율로 나누고, 한쪽만 있으면 그 자원이 수요를 채웁니다.

곡물 수요를 채우지 못하면 소비 전 곡물 부족량을 기준으로 `floor(부족량 / 10)`명을 줄이며, 어떤 부족량이든 최소 1명은 감소합니다. 감소 순서는 무직, 노동자, 농민입니다. 단백질 부족은 사망을 일으키지 않고 성장을 막습니다. 곡물 부족이 없으면 성장량은 `floor(min(곡물 잉여, 단백질 잉여 * 5) / 10)`이며 새 인구는 무직으로 추가됩니다.

건설 부문이 생산한 건설력은 재고로만 저장합니다. 자동 건설이나 자동 소비는 없습니다.

## 실행

에디터에서 F6 또는 F5로 실행하거나 프로젝트 디렉터리에서 다음을 사용합니다.

```powershell
godot --headless --path . --quit-after 2
godot --path .
```

Godot 4 실행 파일이 없는 환경에서는 위 명령을 실행할 수 없습니다. 프로젝트는 `project.godot`의 메인 씬으로 `scenes/Main.tscn`을 사용합니다.
